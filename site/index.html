Quickstart

5-step developer setup

About 30 minutes · $0 a month on Cloudflare's free plan · only Stripe's standard fee per sale.

1. Create two Ed25519 keypairs

The license private key becomes a Worker secret. The update private key never leaves your Mac. Only the two public keys ship inside your app.

zsh 
swift run license-tool --scheme MYAPP-V1 --init-keypair
swift run license-tool --scheme MYAPP-V1 --init-update-keypair

2. Create a Payment Link and a restricted Stripe key

No webhooks. Point the Payment Link's redirect at https://activate.myapp.com/thank-you?session_id={CHECKOUT_SESSION_ID}, then create a restricted key (rk_live_...) with these 4 read-only permissions:

Stripe Restricted Key Scopes 
Checkout Sessions : Read
PaymentIntents    : Read
Charges           : Read
Disputes          : Read

3. Deploy the Cloudflare Worker

One Worker and one SQLite Durable Object, on the free plan. Set TICKET_SCHEME, APP_NAME and APP_URL_SCHEME in worker/wrangler.jsonc first.

zsh 
npx wrangler -c worker/wrangler.jsonc deploy
npx wrangler -c worker/wrangler.jsonc secret put ED25519_PKCS8_B64
npx wrangler -c worker/wrangler.jsonc secret put STRIPE_SECRET_KEY
npx wrangler -c worker/wrangler.jsonc secret put STRIPE_ALLOWED_PAYMENT_LINKS

4. Add SeatStamp to your app and handle every outcome

Paste in the two public keys, gate paid features with verifyGateAccess(), and handle each ActivationOutcome so a pending payment or a wrong clock gets a clear message.

Swift 
import SeatStamp

let kit = SeatStampManager(
    scheme: "MYAPP-V1",
    licensePublicKeyBase64: "<LICENSE_PUBLIC_KEY>",
    updatePublicKeyBase64: "<UPDATE_PUBLIC_KEY>",
    activationEndpoints: [URL(string: "https://activate.myapp.com")!],
    trialLengthDays: 30,
    maxSeats: 2,
    bundleID: "com.example.myapp"
)

switch await kit.activate(key: pastedKey) {
case .activated:        showStatus("Unlocked. Thank you!")
case .paymentPending:   showStatus("Your payment is still clearing.")
case .seatLimitReached: showStatus("All Macs are in use. Deactivate one first.")
case .invalidKey:       showStatus("That key wasn't recognized, or was refunded.")
case .clockSkew:        showStatus("Your Mac's clock is off. Turn on automatic time.")
case .networkError:     showStatus("Couldn't reach the server. Try again.")
case .unconfigured:     showStatus("This build has no activation server.")
}

5. Sign each release on your own Mac

license-tool signs the version, the download URL, and the file's SHA-256 and size with your offline update key. Upload version.json and the .dmg to any static host.

zsh 
swift run license-tool --scheme MYAPP-V1 \
  --sign-manifest version.json \
  --artifact MyApp-1.2.dmg
Ready to ship.

Engineering Honesty

Security guarantees, non-goals & privacy

What SeatStamp enforces, and what no offline desktop software can prevent.

Enforced by crypto & edge

  • Offline Ed25519 ticket and update verification (sha256 + size + manifest_seq + Gatekeeper quarantine).
  • A browser checkout handoff (chk_) is bound to the first Mac that polls for it.
  • Monotonic 4-anchor local trial clock (blocks macOS system clock rollback).
  • Yearly seat-move budget (SEAT_RELEASES_PER_YEAR) and a local revokedBefore floor that rejects tickets pasted back after Deactivate.
  • Stripe errors, pending payments, and won disputes never wipe a valid buyer's seats.

Explicit offline non-goals

  • Patching your compiled app on the buyer's own Mac skips local checks. This is true of every offline Mac app.
  • Deleting all 4 local trial anchors (one of them in the Keychain) at once, or using a fresh macOS user, restarts the trial.
  • Remotely disabling a refunded copy that never checks for updates, because unlocked Macs never phone home.

Accurate privacy posture

  • Worker SQLite stores zero emails and zero IP addresses; records are keyed by a hash of the purchase key.
  • Inactive seat rows auto-purge after 30 days, and --erase-key deletes an order record on request.
  • Stripe (payment processor) and optional Resend (backup email sender) process buyer data under their own policies.
